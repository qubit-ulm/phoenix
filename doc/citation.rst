How To Cite
===========

Name: ``PHOENIX``

Acronym: Parallel Hybrid Operations for Enhanced Numerical Implementations and
eXecutions

If you use PHOENIX in research work, please cite the software and include the
repository reference.

Recommended plain-text citation
-------------------------------

::

   Matthias Kost, Martin B. Plenio. PHOENIX: Parallel Hybrid Operations for Enhanced Numerical
   Implementations and eXecutions. Version 1.0.
   https://github.com/qubit-ulm/phoenix

----------------------------------
